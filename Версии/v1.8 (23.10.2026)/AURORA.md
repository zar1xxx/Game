# «В погоне за бензином» на ОС Аврора

Официальный Godot не умеет собирать игры для Авроры. Это делает порт от сообщества,
Godot 4.4.1 с платформой **AuroraOS**: https://github.com/savegame/godot,
релиз `4.4.1-auroraos-4`. Игра уже подготовлена под него, а сборка RPM выполняется на вашем компьютере.

## Что уже сделано в проекте

- **Пресет «Aurora OS»** в `export_presets.cfg`:
  - ID приложения `ru.vladimkorol.vpogonezabenzinom`;
  - архитектуры armv7hl и aarch64;
  - версия 1.8;
  - разрешение Audio.
- **Иконки** 86, 108, 128 и 172 px лежат в `icons/`.
- **Резервная копия пресета** лежит в `aurora/export_preset_aurora.cfg`. Обычный Godot, не порт, при сохранении
  проекта молча удаляет пресеты неизвестных платформ. Если пресет пропал, вставьте блок из копии
  обратно в конец `export_presets.cfg`.
- **Управление.** Под Авророй игра включает только сенсорные кнопки ◀ ▶ и ТОРМОЗ: в порте пока нет
  акселерометра и вибрации. Пункты «Наклон» и «Вибрация» в настройках скрыты.
- **Сохранения.** Рекорд записывается при сворачивании игры (потеря фокуса), а игра сама встаёт на паузу.
- **Кнопки «Назад» на Авроре нет.** Пауза — кнопка «II» в правом верхнем углу.

## Как собрать RPM

1. **Установите Аврора SDK** с https://developer.auroraos.ru (раздел «Загрузки» → Аврора SDK).
   Для Godot нужна командная утилита `sfdk`, Qt Creator из SDK не обязателен.
2. **Скачайте порт** со страницы релизов https://github.com/savegame/godot/releases
   (тег `4.4.1-auroraos-4` или новее):
   - редактор для своей ОС;
   - шаблоны экспорта для Авроры (`arm32`, `arm64`, при желании `x86_64` для эмулятора).
3. **Откройте проект в редакторе из порта**: Редактор → Настройки редактора → Export → AuroraOS.
   - `aurora_sdk/sdk_path` — папка установленного SDK (например, `~/AuroraOS`).
   - Пути к шаблонам `arm32` и `arm64`, если редактор не нашёл их сам.
4. **Подпишите пакет.** Проект → Экспорт → «Aurora OS» → поля `sign/key` и `sign/cert`.
   - Для отладки подойдут публичные тестовые ключи «regular» из документации Авроры.
   - Для магазина RuStore нужны собственные ключи разработчика.
5. **Нажмите «Экспорт проекта».** Получатся RPM-файлы для каждой архитектуры.
6. **Установите игру на телефон** в режиме разработчика. Подключите телефон к SDK, затем:
   ```
   sfdk device install build/aurora/<файл>.rpm
   ```
   Или скопируйте RPM на телефон и откройте его в «Файлах».

Подробная официальная инструкция:
https://developer.auroraos.ru/doc/5.1.1/software_development/guides/godot_export.
Сообщество разработчиков игр под Аврору: https://t.me/auroraosgames.

## Ограничения порта, которые стоит знать

- Рендер только GL Compatibility (проект уже на нём).
- Нет акселерометра и вибрации. Звук и мультитач работают.
- Порт неофициальный. Если что-то не собирается, сначала обновите порт и шаблоны до последнего релиза.
